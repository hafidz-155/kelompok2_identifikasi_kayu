# Klasifikasi Jenis Kayu Menggunakan GLCM dan KNN

## Deskripsi
Aplikasi ini digunakan untuk mengklasifikasikan jenis kayu berdasarkan citra tekstur menggunakan metode GLCM dan algoritma KNN.

## Fitur
- Upload gambar kayu
- Ekstraksi fitur GLCM
- Klasifikasi menggunakan KNN
- Menampilkan hasil prediksi

## Teknologi
- Python
- Flask
- OpenCV
- Scikit-Learn
- NumPy
